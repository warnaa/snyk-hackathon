      What happened?

      The weakness: untrusted document content treated as instructions. The Archivist's real task was only to summarize the parchment. But the parchment was written by you, an untrusted source. When a document contains text that looks like a command, a language model can follow it as if it came from its operator. This is called prompt injection.

      Why the secret leaked: the vault phrase sat in the agent's context with only an instruction not to reveal it. Instructions are not a security boundary; injected text can override them.

      The fix: keep the secret out of the agent's context entirely. Summarizing a parchment never needed the vault phrase, so the mended Archivist starts a fresh conversation that never receives it. The replay shows what was observed; the structural protection is that the secret is simply not there to leak.

      What happened?

      The weakness: the tool trusted the agent. The Warden had an unlock_gate tool, and the tool unlocked the gate whenever the agent called it. So anyone who could persuade the agent could open the gate. This is excessive agency: the permission check lived only in the model's judgement.

      Why persuasion worked: claiming the keeper had approved is just text. The model cannot verify it, and agreeing to an action does not make it authorized.

      The fix: the tool handler checks permissions itself. Your role is fixed by the application as visitor, and the model cannot supply or change it. Only a keeper may unlock the gate, so even if the agent calls the tool, the handler refuses.
